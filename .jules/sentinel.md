# Sentinel's Security Journal

## 2026-10-22 - Mermaid SVG Sanitization and Strict Security Level
**Vulnerability:** In `app/src/lib/mermaid.ts`, `mermaid.initialize` was configured with `securityLevel: 'loose'`. Because the resulting SVG output is injected directly into the DOM using `dangerouslySetInnerHTML` in diagram viewer components (`DiagramViewer` and `MarkdownDiagram`), diagram definitions containing inline script handlers, `javascript:` pseudoprotocols, or embedded HTML elements can execute arbitrary JavaScript in the context of the user's session (Stored / DOM XSS).
**Learning:** Mermaid diagrams generated by LLM pipelines or user-uploaded DSL code cannot be trusted as purely decorative text. Mermaid provides built-in DOMPurify sanitization and sandbox isolation when configured with `securityLevel: 'strict'`, stripping dangerous executable tags and inline click callbacks.
**Prevention:** Always initialize Mermaid with `securityLevel: 'strict'` when rendering diagrams in web clients, especially when diagram outputs are passed into React DOM via `dangerouslySetInnerHTML`.
